# 口径与边界（完整定义）

回答用户时如果被追问「这个分数怎么来的」「凭什么说收敛了」，答案都在这里。

## 1. 就绪度评分（0-100）

分五个维度：环境一致性 / 数据集一致性 / 参数一致性 / 实验记录完整度 / 结果一致性。

三条必须知道的口径：

- **未核验的维度不给分也不扣分** —— 它既不进分子也不进分母。
  「没上传实测结果」不等于「论文有缺陷」。
- **一条都没核验时总分是「—」而不是 100** —— 凭空给满分比不给分更糟。
- **就绪度评价被审对象，可信度评价本次审计本身** —— 两者严格区分，不要混着说。

`audit_confidence`（审计可信度）由解析覆盖率、证据自证通过率等算出，
答「这次审计靠不靠谱」；就绪度答「这篇论文/这份代码好不好复现」。

## 2. 风险等级

| 等级 | 触发条件 |
| --- | --- |
| 高 | 关键复现参数（如学习率）不一致，会直接改变训练过程与结论 |
| 中 | 重要参数缺失或未固定（如种子、数据集版本），影响可比性 |
| 低 | 影响面小的差异 |
| 无 | 一致项 |

风险分级**附带判定理由**，不只给一个标签 —— 理由写在结论的 `risk_reason` 里。

## 3. 置信级

只做两级：`confirmed`（规则确证）/ `inferred`（推断）。
`inferred` 的结论在报告里会明确标注来源渠道（如「读图推断」），
不参与文本层的自证，也不按已确认处理。

## 4. 可复现性评级

| 等级 | 分数 |
| --- | --- |
| A | ≥ 85 |
| B | ≥ 70 |
| C | ≥ 55 |
| D | < 55 |

从 100 分起步**逐条扣分**，扣分理由逐条可查。常见扣分项与分值：

| 扣分项 | 分值 |
| --- | --- |
| 高风险不一致 | −8 |
| 中风险不一致 | −4 |
| 低风险不一致 | −2 |
| 要求固定但未固定（如种子） | −6 |
| 论文或代码内部自相矛盾 | −5 |
| 论文有但代码缺失 | −3 |
| 双路核对出现分歧 | −4 |
| 论文页级覆盖率过低 | −10 |
| 代码解析失败 | −5 |
| 一条引证都没有 | −3 |

**同一个参数只按最重的一条扣一次** —— 否则一个坏参数会被反复罚，
分数失去可比性。

## 5. 迭代回边的收敛判据

这是最容易被问「你是不是自己证明自己」的地方，口径写死如下：

**收敛 = 可落地**，三个条件**同时**满足才算：

1. 根因定位到唯一生效点（置信级为 `confirmed` 或 `inferred` 中的高/中档）；
2. 修正草案给得出来（且没有被补丁闸门拒绝）；
3. 复验时该冲突真的消失。

**不是**「把数字改成和论文一样再看是否相等」—— 那种做法恒成立，
收敛率永远是 100%，等于什么都没说。

另外两条：

- **最多 3 轮**；任一非观察轮没有改善就停，不空转。
- **第 3 轮是观察轮**（把复现目标换成代码一侧再看一遍），
  `resolved` 与 `improved` 强制为假，理由写明「换复现目标不算解决冲突」。

## 6. 引证（搜）

- 出自优先级：**论文页优先**，其次代码 `文件名:行号`；
- 判定 `mismatched`：出处片段里**实际上并不包含**结论所述的值；
- 判定 `inferred_only`：该结论只有推断级证据、论文侧没有直接声明；
- 检索方式自述：**字面检索（同义词扩展 + 取值命中），不是向量/语义检索** ——
  这句话要照实说，别把它说成"语义检索"。

## 7. 外部检索

- **默认关闭**；
- 开启后返回的线索一律带 `unverified=True`；
- 「未核验」这句提醒由模块**强制补上**，不依赖模型自觉写入；
- 外部线索不得当作出自论文的引证使用。

## 8. 绝不越界的三件事

1. **不写文件**：全过程只读输入。迭代回边的修正是内存中的反事实推演。
   （对应测试会做「目录哈希一致」的硬自检。）
2. **不执行用户代码**：「算」用 `ast` 白名单，只允许数字、四则运算、
   乘方、取模、整除、一元正负、`pi`、`e`；函数调用、变量名、列表、
   多语句、超长表达式一律拒绝。
3. **不改用户代码**：补丁只作为**草案**呈现，落不落地由人决定。

## 9. 已知的行为差异（如实告知，不粉饰）

- 多智能体模式**不执行**「AI 风险归因」这一站（AI 给每条问题配点评），
  因此界面进度条是 9 项而非 10 项。审计结论本身不受影响
  （三版同跑的结论逐条一致，有测试证据）。
- 「算」的量纲提示阈值是 **10²** 起步 —— 只差 10 倍是常见合法差异，
  报了反而变噪声。
