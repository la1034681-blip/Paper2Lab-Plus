# 论文 x 代码 复现一致性审计

## 这个技能解决什么问题

拿到一篇论文和一份「作者自己的实现」或「复现者的开源实现」，
最费时间的不是读论文，而是**逐项核对两边的实验参数到底对不对得上**：
学习率是 1e-4 还是 0.001、batch size 是 32 还是 64、随机种子固定了没有、
数据集是 CIFAR-10 还是某个 v2 版本……

本技能把这件事做成一条**可追溯的流水线**：两边各自抽取参数 → 归一化 → 逐项比对，
输出「哪些参数对不上」，并且**每条结论都带证据出处**——
论文侧给到页码与所在章节，代码侧给到文件与行号。

## 什么时候用

**该用**（出现下列任一情形）：

- 用户给出一篇论文（PDF）和一份代码（zip 或目录），问能不能复现 / 哪里对不上；
- 用户问「论文与代码的参数是否一致」「帮我做一次复现审计」；
- 用户想评估一份开源实现的可复现性，要一份「照做就能跑」的步骤清单；
- 用户需要为每条差异找到原文出处（写复现报告、答辩、审稿）。

**不该用**：

- 只有论文、没有代码 —— 本技能的核心是**两边比对**，单侧材料请改用论文阅读类能力；
- 非机器学习 / 深度学习领域的论文（本技能目前只在该领域校验过参数语义）；
- 想跑训练来验证结论 —— 本技能**不执行任何用户代码**（见下方边界第 2 条）。

## 输入

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 论文 | 文件路径 | 是 | `.pdf`，最好是可选中文本的版本；扫描件会降级为图像通道，结论会如实标注 |
| 代码 | 路径 | 是 | `.zip` 压缩包，或已解压的目录 |
| 实测结果 | 文件路径 | 否 | 可选的 `results.json`，提供后会把「论文宣称指标 vs 实测指标」一并核验 |
| 模式 | 枚举 | 否 | `classic`（默认，最快）/ `multagent`（多智能体对撞，结论更全） |
| 闭环 | 布尔 | 否 | 是否追加「算 / 搜 / 做 + 迭代回边」四件套，默认关 |

## 怎么执行

### 第 1 步 · 先做最小核对（默认动作）

只回答「哪几个参数对不上、证据在哪」，最省时间。
如果结论显示两边**本来就一致**，往往不需要再往下走。

### 第 2 步 · 按需加深

- 要看**引证**（每条结论回原文第几页）：走「搜」；
- 要**交叉验算数字**（比如论文写 1000 步、代码写 0.05 比例，换算是否对得上）：走「算」；
- 要一份**可执行方案 + 可复现性评分**：走「做」；
- 想让它**自己找根因并给修正草案**：走「迭代回边」（有界，最多 3 轮）。

### 第 3 步 · 呈现结果

给用户的内容里必须**带着出处**，并且**分歧要如实并列**，不要替用户做取舍。
已知会被报出来的分歧类型见 `references/parameters.md` 末尾。

## 输出长什么样

一份审计摘要，包含：

- **统计**：共核对多少项、其中一致 / 不一致 / 单侧缺失各几项；
- **逐条结论**：参数名、论文侧的值 + 页码、代码侧的值 + 文件与行号、状态、风险等级、置信级；
- **就绪度**：0-100 的分维度评分（环境 / 数据集 / 参数 / 实验记录 / 结果一致性），
  没核验的维度**如实标注「未核验」而不是给满分**；
- **自检**：证据自证通过了几条（每条结论的原文片段是否真的包含所述的值）；
- **（可选）** 引证覆盖率、量纲提示、七步复现方案与 A/B/C/D 评级、逐轮迭代留痕。

## 四条边界（回答用户时必须照实说明）

1. **只读，绝不改任何文件。** 迭代回边里的「修正」只是内存中的反事实推演，
   不会写进用户的代码或论文。
2. **不执行用户代码。** 「算」走白名单表达式求值（只认数字与四则运算），
   要 GPU 的训练类复现一律标注「需实机验证」，不会静默假装跑过。
3. **有界自主。** 迭代回边最多 3 轮，第 3 轮是「换一个复现目标再看」的观察轮，
   **不计入收敛** —— 否则收敛率永远是 100%，那种数字没有意义。
4. **外部检索默认关闭。** 若启用，返回的外部线索一律标记「未核验」，
   不得当作出自论文的引证使用。

## 快速开始

```bash
# 1) 环境自检（会告诉你缺什么）
python scripts/check_env.py

# 2) 最小核对
python scripts/audit.py 论文.pdf 代码.zip

# 3) 完整闭环（含引证 / 复算 / 复现方案 / 迭代）
python scripts/audit.py 论文.pdf 代码.zip --mode multagent --loop --pretty
```

若提示找不到 `paper2lab` 包，设置环境变量指向项目根目录后重试：

```bash
export PAPER2LAB_ROOT=/path/to/paper2lab      # Windows: set PAPER2LAB_ROOT=D:\path\to\paper2lab
```
